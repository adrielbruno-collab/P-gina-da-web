Sobre o Projeto

Projeto por: ADRIEL

Bem-vindo ao repositório do Meu Primeiro Blog! Este é um projeto inicial criado para praticar o desenvolvimento web e compartilhar conhecimentos sobre tecnologia e programação.

📜 Descrição

Este projeto é uma página web estática construída com estruturação em HTML5 e estilização CSS3 moderna e responsiva. O objetivo principal é servir como um diário de aprendizado e um espaço para publicar artigos sobre o mundo da tecnologia.

🛠️ Tecnologias Utilizadas

  • HTML5: Para a estruturação e semântica da página (cabeçalho, artigos, títulos, etc).
  • CSS3: Para a estilização visual moderna, utilizando variáveis CSS, gradientes e layout responsivo.

🚀 Como Executar o Projeto

  1. Faça o download ou clone este repositório para o seu computador.
  2. Navegue até a pasta onde o arquivo se encontra.
  3. Clique duas vezes no arquivo index.html.
  4. O seu navegador padrão vai abrir e exibir o blog na tela!
