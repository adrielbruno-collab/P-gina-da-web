Bem-vindo ao repositório do **Meu Primeiro Blog**! Este é um projeto inicial criado para praticar o desenvolvimento web e compartilhar conhecimentos sobre tecnologia e programação.

## 📜 Sobre o Projeto

Este projeto é uma página web estática simples construída com estruturação em HTML e estilização básica em CSS. O objetivo principal é servir como um diário de aprendizado e um espaço para publicar artigos sobre o mundo da tecnologia.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Para a estruturação e semântica da página (cabeçalho, artigos, títulos, etc).
* **CSS3:** (Embutido) Para a estilização visual, como cores de fundo (`blueviolet`), tipografia e alinhamento.

## 🚀 Como Executar o Projeto

Como é um projeto puramente frontend estático, executá-lo é muito simples:

1. Faça o download ou clone este repositório para o seu computador.
2. Navegue até a pasta onde o arquivo se encontra.
3. Clique duas vezes no arquivo `index.html` (ou o nome que você deu ao arquivo HTML).
4. O seu navegador padrão vai abrir e exibir o blog na tela!
